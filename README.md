## 🌟 Featured Projects

### 🤖 [Bug2PR](https://github.com/venkataCharan22/Bug2PR) — *Autonomous Bug-to-PR Pipeline*

> **8-agent AI system that takes an error log and opens a real GitHub PR with a fix, regression test, and security audit in ~60 seconds.**

- Built on **IBM Bob CLI** as the primary LLM, with Gemini, Groq, and Ollama as graceful fallbacks
- LangGraph orchestrating **8 specialist agents** (Log Analyst → Code Reader → Code Retrieval → Root Cause → Fix Engineer → Test Writer → Security Auditor → Reporter)
- Multi-project support, real-time WebSocket-streamed agent debate UI, sandbox pytest verification, per-project MTTR dashboard
- **Stack:** Python · FastAPI · LangGraph · React · ChromaDB · IBM Bob · GitHub API · Slack

### 💊 [MediMatch AI+](https://github.com/venkataCharan22/medimatch) — *KG-Augmented Drug Discovery & Prescription Platform*

> **🏆 Winner — Idea to Impact Innovation Contest 2025** (1st of 150+ teams) · 📄 *Paper submitted to IEEE ICAIHC 2026*

- Dual-repo biomedical platform: **Flask backend** + **Flutter mobile**
- **KG-grounded RAG copilot** built on a **45K+ triple PharmaSage knowledge graph** (FAISS + Groq Llama 3.3)
- **RDKit-based drug target prediction** using 2048-bit Morgan fingerprints + Tanimoto similarity
- **Gemini Vision prescription OCR** — achieved **95% accuracy** across 150+ test images ([prescriptionToText](https://github.com/venkataCharan22/prescriptionToText))
- 15+ REST endpoints, SQLAlchemy ORM, multi-source drug lookup (RxNorm, PubChem, ChEMBL, DrugCentral), DDI checking
- Deployed on **Google Cloud Run** with Docker + Gunicorn
